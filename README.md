# Nail Salon Management

## Project Description
This project is designed to manage the operations of a nail salon, including appointment scheduling, client management, and staff administration. The application aims to enhance the efficiency of salon operations while providing an excellent experience for clients.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Styling:** Tailwind CSS
- **Authentication:** JSON Web Tokens (JWT)

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/Alex-skigo99/nail-salon-management.git
   ```
2. Navigate to the project directory:
   ```bash
   cd nail-salon-management
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```
5. Open your browser and visit `localhost:3000` to access the application.
